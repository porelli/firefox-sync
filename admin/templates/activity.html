What is counted

What the Sync server counts in its metrics: the client errors of the storage API (Hawk authentication, invalid requests, items too large), conflicts and the quota, and the tokens it refused (an old or bad sign-in, old keys, max users full, a database error). It sends nothing for its 5xx, so a database down shows in the health checks instead, and nothing for 404 or 412, which are answers to Firefox. The metrics carry no endpoint: the kind is in the name of the metric.
